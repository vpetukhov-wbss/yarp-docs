Three directions for the same documentation shell

All three use the same information architecture (35 pages across 11 sections) and the same real content — the Overview of YARP page, with its actual code samples and callout — so the comparison is about surface, not structure.

01 · Learn

Content-first docs shell

Neutral slate greys, a single confident blue accent, system UI type. Closest to Microsoft Learn and angular.dev — the least surprising choice for a .NET audience, and the one that scales to 35 pages without fighting the reader.

Same shell, rebuilt for people who live in terminals and logs. Monospace throughout, an amber accent borrowed from HTTP's own 3xx status class, and a live traffic ticker under the header — the one real risk in the set.

03 · Manual

Numbered reference, print heritage

Flax paper, Rockwell slab heads, Cambria body — read as an authoritative book, not a website. Parts I–XI and sections 1–35 are a real numbering scheme, not decoration, since the content genuinely is that sequence. Prussian blue instead of the expected terracotta.
